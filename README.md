# Test app for expo-widgets and @expo/ui pull requests

Screenshots and the throwaway app used to test the expo-widgets `relevanceScore`, `getEndedInstances`, and `activityId` pull requests and the @expo/ui `renderingMode` pull request. Copy `widgets-pr-tester/` into `apps/` of an expo checkout with those branches merged, run `pnpm install`, then `npx expo prebuild -p ios` and build it.
